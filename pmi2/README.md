# Материалы расширенной серии испытаний (21.08.2026)

Экспорт стенда без правок. Модели обозначены условно М1/М2/М3.

- `protokol.txt` — протокол сравнительных испытаний, как его выгрузил стенд
- `reestr.txt` — реестр из 150 заданий с эталонами, зафиксированный до прогона
- `rezultaty.csv` — результаты по каждому заданию, три плеча
- `zhurnal.json` — полный журнал обращений к моделям

Две неподтверждённые оценки («?»), отмеченные в протоколе, были решены вслепую
после прогона — обе не в пользу заявляемого способа. Итоговые доли недостоверных
утверждений с учётом этого: М1 — 8,7 %, способ — 5,3 % (в автозачёте протокола
8,1 % и 4,7 %). Остальные показатели не менялись.

Оговорка об отпечатке: стенд этой серии считал SHA-256 по своему внутреннему
представлению реестра, и по текстовому экспорту `reestr.txt` он не воспроизводится.
В новой серии (`../reestr.txt`) правило подсчёта записано в самом файле и проверяется
одной командой.
